Memory storyboard

Reconstruct a taught sequence using frames and captions.

How to run it

  1. Name the sequence

    Specify the process or series already taught.

  2. Rebuild the frames

    Draw simple stages from memory in order.

  3. Explain the transitions

    Add captions showing why one stage leads to the next.

  4. Check the sequence

    Compare with the reference and correct missing stages.

Prepare

A blank set of four to six frames; a taught sequence.

Check learning

Check order and causal links, not artistic quality.

Adapt for your class

Offer fewer frames or spoken captions.
