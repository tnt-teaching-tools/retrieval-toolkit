Picture prompts

Use a familiar image as a cue for remembered knowledge.

How to run it

  1. Choose the image

    Use a diagram or photograph connected to taught material; hide answer labels.

  2. Recall details

    Students write remembered labels, steps or explanations independently.

  3. Explain connections

    Ask learners to connect the visual to the taught ideas.

  4. Reveal and check

    Show a checked explanation and correct mistakes.

Prepare

A relevant image with answer labels hidden

Check learning

An image containing all the answers can turn the task into copying. Keep the initial cue useful without revealing the target knowledge.

Adapt for your class

Provide a verbal description or accessible alternative to the image.
