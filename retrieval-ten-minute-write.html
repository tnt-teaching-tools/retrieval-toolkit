Short recall write

Use a few minutes of writing to explain previously taught knowledge.

How to run it

  1. Set the question

    Choose a prompt drawing on familiar taught content.

  2. Retrieve a plan

    Jot key ideas from memory before writing.

  3. Write for four minutes

    Develop a short explanation using your recalled knowledge.

  4. Check the content

    Compare with criteria; correct knowledge and missing reasoning.

Prepare

A focused prompt, paper and a checked model or criteria.

Check learning

Focus feedback on accurate knowledge and one key explanation, rather than marking writing at length.

Adapt for your class

Use bullets, dictation or a shorter writing stage while preserving independent recall.

Credits & source

Needham describes ten-minute recall-and-application writes. This shorter starter adaptation uses a brief closed-note plan, four minutes of writing and checked feedback.
