Sticky-note quizzing

Students write, exchange and answer small recall prompts.

How to run it

  1. Write a prompt

    From memory, write one clear question and keep its answer separately.

  2. Check the question

    Teacher checks the intended answer before notes are exchanged.

  3. Exchange and retrieve

    Answer a received prompt independently with notes closed.

  4. Return and verify

    Return it to the writer; resolve uncertainty with the teacher.

Prepare

Sticky notes; a taught topic; a reference for teacher checks.

Check learning

A question writer’s memory is not automatically an answer key.

Adapt for your class

Supply a question stem or use a shared digital board.

Credits & source

Hall Houston identifies this activity as his own in the linked TESOL blog. This subject-neutral adaptation adds individual thinking and teacher-checked feedback.
