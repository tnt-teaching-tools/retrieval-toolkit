Frayer model from memory

Recall a concept’s definition, features, examples and non-examples.

How to run it

  1. Set the concept

    Name the taught concept; close reference materials.

  2. Recall its boundaries

    Write a definition and important characteristics.

  3. Generate examples

    Add examples and non-examples, explaining the difference.

  4. Check all four sections

    Verify against taught content and correct weak boundaries.

Prepare

A blank four-section organiser and a previously taught concept.

Check learning

A non-example should help explain a boundary, not be an unrelated item.

Adapt for your class

Use sketches or one example in each box before adding more.
