Inkshedding

Recall in writing, then exchange a written dialogue.

How to run it

  1. Write privately

    Free-write a short explanation from memory.

  2. Exchange pages

    Read a partner’s response after both have attempted recall.

  3. Add a response

    Question, clarify or connect a point in writing.

  4. Check and return

    Verify disputed content; each writer corrects their own account.

Prepare

Paper and a focused prompt about taught knowledge.

Check learning

Separate first recall from additions learned through the exchange.

Adapt for your class

Use brief bullet points or an accessible shared document.

Credits & source

Inkshedding was developed by Russ Hunt and Jim Reither. Lindsey Albracht’s Baruch College guide explains a classroom version for reviewing earlier material through written dialogue. The linked guide describes a longer discussion activity; this short retrieval adaptation asks students to recall previously taught content without notes before exchanging writing, then check accuracy.
