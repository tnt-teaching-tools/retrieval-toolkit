Draw from memory

Show a taught idea in a simple sketch, then explain it.

How to run it

  1. Choose an idea

    Name a concept students have already studied.

  2. Sketch from memory

    Show its important parts or relationships simply.

  3. Add meaning

    Label the sketch and explain one important connection.

  4. Check the account

    Compare with taught content; fix omissions and errors.

Prepare

Blank paper and a familiar concept; no model visible initially.

Check learning

Assess accurate meaning, not drawing skill.

Adapt for your class

Use shapes, arrows, tactile models or a spoken description.

Credits & source

The Learning Scientists describe drawing from memory as a retrieval format. This guide is a classroom adaptation, not a claim that the authors invented drawing or that drawing always outperforms other formats.
