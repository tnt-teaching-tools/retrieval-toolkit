# Retrieval Toolkit

Free classroom toolkit with 38 activity guides, 38 editable PowerPoint templates, 34 Word templates and two links to Kagan’s original resources.

Each download contains a credit and source link. Keep these when sharing a template. The full sources and adaptations are recorded in sources-and-acknowledgements.md and the website’s activity guides.

Published at https://tnt-teaching-tools.github.io/retrieval-toolkit/
