Blank-diagram recall

Restore missing labels and explain what they mean.

How to run it

  1. Set the focus

    Provide the outline without the labels or answer bank.

  2. Retrieve the labels

    Fill labels from memory before opening notes.

  3. Explain relationships

    Describe what two labels do or how they connect.

  4. Check and correct

    Restore accurate labels and meanings using the key.

Prepare

An unlabelled version of a familiar taught diagram and a checked key.

Check learning

Correct placement and an explanation matter more than a list of names.

Adapt for your class

Enlarge the diagram; add limited cues when needed, then fade them later.

Credits & source

Jones gives an unlabelled diagram as an example of a retrieval cue. This guide adapts that example across subjects; the original inventor of diagram labelling is not verified.
