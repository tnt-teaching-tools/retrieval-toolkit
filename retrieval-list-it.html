List it

Recall a focused set, then explain your choices.

How to run it

  1. Name a category

    Choose a bounded category from previously taught content.

  2. Recall a short list

    Everyone records remembered examples without notes.

  3. Add the reasoning

    Ask students to explain why one item belongs in the category.

  4. Check the set

    Verify each item and correct false inclusions.

Prepare

Paper or mini whiteboards

Check learning

A longer list is not necessarily better understanding. Check accuracy and explanations.

Adapt for your class

Set an achievable list length and offer narrower category cues.

Credits & source

Hall Houston describes List It! in his TESOL article and attributes the published classroom example to Kate Jones’s Retrieval Practice (2019). Listing from memory is a wider shared routine. This independently written adaptation adds a bounded category, an explanation and teacher checking.
