Flashcard practice

A short classroom round: recall from prepared cards, then check.

How to run it

  1. Hide the answer

    Put prompt sides up and shuffle the cards.

  2. Commit an answer

    Say or write your answer before turning a card over.

  3. Check honestly

    Compare meaning and detail, then correct the response.

  4. Retry a missed card

    Set the answer aside and reattempt a missed prompt independently before ending the starter.

Prepare

Teacher-prepared, checked prompt-and-answer cards for previously taught content.

Check learning

Recognising an answer after flipping is different from retrieving it. Avoid racing for the highest card count.

Adapt for your class

Use a small teacher-selected set; work seated in pairs or answer on paper.
